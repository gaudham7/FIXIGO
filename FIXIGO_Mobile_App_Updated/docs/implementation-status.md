# Implementation Status

## Included in this starter
- Expo Router mobile application shell.
- Customer/worker role entry screens.
- Demo customer service-request form calling FastAPI.
- FastAPI health endpoint.
- Demo service category endpoint.
- Demo in-memory service-request create/read endpoints.
- Basic Next.js admin dashboard shell.
- Docker Compose PostgreSQL and Redis services.
- Backend smoke tests.

## Not yet implemented
- Production authentication and role-based authorization.
- Persistent SQLAlchemy repositories and Alembic migrations.
- Supabase integration and row-level security policies.
- Worker onboarding and document verification.
- AI request understanding, vision and speech processing.
- Worker matching and pricing engine.
- Booking lifecycle, quotation approval and payments.
- Messaging, push notifications, live location and ETA.
- Admin API integration, dispute workflow and analytics.
- Production monitoring, backup, deployment and security hardening.

Do not use the demo endpoints with real customer data.
